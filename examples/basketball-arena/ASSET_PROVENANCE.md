# Basketball arena asset provenance

All five PNGs in `public/assets` were generated for this example with the
built-in OpenAI image generation tool on 2026-08-24. They are original,
unbranded game assets with no copied team, league, or product marks.

## Prompt set

- `basketball-court.png`: strict orthographic top-down 5:3 indoor maple court,
  navy safety border, teal/coral key accents, readable regulation-inspired
  markings; no hoops, balls, people, text, numbers, logos, or watermarks.
- `basketball-ball.png`: isolated overhead orange basketball arcade sprite with
  readable charcoal channels and genuine transparency; no text or branding.
- `basketball-hoop.png`: isolated 15-degree top-down freestanding glass
  backboard, coral rim, white net, and navy base, with the rim projecting right
  so one asset can be mirrored; genuine transparency and no branding.
- `basketball-avatar.png`: isolated full-body teal/navy/coral street-basketball
  player at a top-down 15-degree game angle; no ball, text, number, or branding.
- `basketball-scoreboard.png`: straight-on navy two-window scoreboard housing
  with teal/coral accents and blank glass areas for live DOM scores; genuine
  transparency, no digits, text, logos, or controls.

The project copies the selected generated outputs into the repository and does
not depend on the generator's default output directory at runtime.
